Python

  • Package taco-eo on PyPI, imported as taco, on Python 3.10 or newer, with wheels for Linux (x86-64, aarch64), macOS (arm64, x86-64) and Windows (x86-64).
  • Reader, and the only TACO writer
pip install taco-eo              # read
pip install "taco-eo[writer]"    # read and write

Python calls libtaco through cffi, runs queries in DuckDB and returns pyarrow.Table objects. Its writer checks metadata with Pydantic, writes Parquet with pyarrow and packs archives with CoZIP. See the API overview for the common data model; this page covers Python calls and behavior.

The public names are open_dataset, read, read_bytes, Dataset, inspect, Contract, Level, Collection, Sample, Asset, Folder, Metadata, Encoding, open_writer, Extension, ExtensionContext, extensions, validate, export, consolidate, TacoError and __version__.

Install

The base package reads every container. The extras add the writer and the runtimes of two extensions.

taco-eocffi, DuckDB 1.5.5 or newer, pyarrow 14 or newer and tqdm. Enough for every reading call on this page, and for Contract and Collection declared from mappings.
taco-eo[writer]Adds cozip, jsonschema, NumPy, Pydantic 2.8 or newer, pyproj and Shapely 2. Needed by open_writer, validate, export, consolidate, taco.extensions and any Level that binds a Pydantic model.
taco-eo[rumi]The writer, rumi-eo 0.19 or newer and geozl 0.34 or newer, for the Rumi extension.
taco-eo[geoenrich]The writer and earthengine-api, for GeoEnrich with backend="earthengine".

A wheel is tagged py3-none-<platform>: cffi loads the core at run time, so one wheel per platform serves every supported Python version. A source install compiles libtaco and needs a C++23 compiler, CMake, Ninja, pkg-config, libcurl 7.83 or newer and OpenSSL 3 or newer.

Importing taco imports pyarrow. The first open loads libtaco, and the first query imports DuckDB. The writer names are imported when first accessed, so a read-only install imports, reads and queries without them. Accessing one without the extra raises ImportError:

ImportError: taco.open_writer needs the writer: pip install 'taco-eo[writer]' (missing cozip)

The native library

The wheel ships the core as taco/_lib/libtaco.so, libtaco.dylib or taco.dll, and in a checkout make core builds it and copies it there. Set TACO_LIB to the path of another build before the first dataset opens. The binding requires C API version 3 and refuses any other. A library that cannot be loaded raises ContainerError at the first open, not at import:

ContainerError: could not load the TACO core from /nope/libtaco.dylib: cannot load library '/nope/libtaco.dylib': dlopen(/nope/libtaco.dylib, 0x0002): tried: ... Build it with `make core` or set TACO_LIB.

taco.__version__ is the version of the installed package, '0.14.2' here.

Reading

open_dataset

taco.open_dataset(source) -> taco.Dataset

Opens a dataset and loads its collection and metadata. Payloads are not read.

sourceText or a path-like object, or a sequence of them, in one of the source forms. A value containing :// is kept as written, and a local path is expanded and resolved. A sequence opens compatible partitions as one dataset, as Source lists and TACOCAT describes. An empty sequence, an empty path or a repeated path, or two paths to one file such as a.zip and file://.../a.zip, raises ValueError, and any other type TypeError.
import taco

url = "https://data.source.coop/major-tom/core-dem/core-dem_MT3000km_0001D_0003L.zip"
dataset = taco.open_dataset(url)
dataset
Dataset('major-tom-core-dem', source='https://data.source.coop/major-tom/core-dem/core-dem_MT3000km_0001D_0003L.zip')

This partition of Major TOM Core-DEM holds 50,178 samples in 1,231,271,133 bytes. The open fetched 2,697,870 bytes of metadata, in 7 to 10 s over four runs here, and a later open read them from the cache in about 1 s. The Dataset keeps one native handle per source and reuses it for every later query. It is a snapshot of the metadata it loaded, except a local FOLDER or TACOCAT, which is read in place (Sources and cache).

Queries run as SELECT * FROM (query) under a WITH defining the relations, so each query must be one statement. DuckDB error line numbers include that wrapper; query failures raise DuckDB exceptions, not TacoError (Errors).

Each thread keeps a DuckDB connection with TimeZone=UTC; read shares it. A forked process, such as a Linux PyTorch DataLoader worker, opens its own connection.

Cache

Remote metadata is cached by the core, under the rules and variables of Sources and cache. Python passes no cache directory of its own, so the core reads TACO_CACHE_DIR, TACO_CACHE_SIZE and TACO_CACHE_REFRESH from the process environment at each open, and setting os.environ before an open is enough:

import os

os.environ["TACO_CACHE_DIR"] = "taco-cache"

import taco

url = "https://data.source.coop/major-tom/core-dem/core-dem_MT3000km_0001D_0003L.zip"
taco.open_dataset(url)
sorted(name for name in os.listdir("taco-cache") if not name.startswith("."))
['CACHEDIR.TAG', 'major-tom-core-dem-zip-https-815e5df3eedb']

The names left out start with a period: the snapshots that open datasets read, which their process removes when it exits. The same root holds the Major TOM index that GeoEnrich downloads while writing. Downloads show a tqdm bar in an interactive terminal and stay silent otherwise. Payloads are never cached.

Writing

A build declares a contract, describes the dataset in a collection, opens a writer, adds samples and runs it. How it works, Contract and Metadata explain the model. This example writes three samples from bytes, so it runs anywhere:

from pydantic import BaseModel, Field

import taco
from taco.extensions.sample.split import Split


class Quality(BaseModel):
    cloud_cover: float = Field(description="Cloud cover in percent")


contract = taco.Contract(
    structure=["image.bin", "mask.bin"],
    metadata=[taco.Level("sample", split=Split, quality=Quality)],
)
collection = taco.Collection(
    contract=contract,
    id="tiny",
    description="Two files per sample, written from bytes",
    licenses=["CC-BY-4.0"],
    providers=[{"name": "Example Lab", "roles": ["producer"]}],
    tasks=["semantic-segmentation"],
)

rows = [("s0", "train", 3.5), ("s1", "train", 41.0), ("s2", "test", 12.0)]
with taco.open_writer(collection, "tiny.zip", overwrite=True) as writer:
    for sample_id, split, cloud in rows:
        writer.add(
            taco.Sample(
                id=sample_id,
                assets=[
                    taco.Asset(f"image of {sample_id}".encode(), path="image.bin"),
                    taco.Asset(f"mask of {sample_id}".encode(), path="mask.bin"),
                ],
                metadata=taco.Metadata(split=Split(split=split), quality=Quality(cloud_cover=cloud)),
            )
        )
    result = writer.run()

result.samples, result.data_files, result.metadata_files, result.size
(3, 6, 2, 32819)

Contract

taco.Contract(*, structure, metadata=None)

The frozen contract: the files of a sample and the fields of each level.

structureAn iterable of str: the declarations, each a fixed file or a variable sequence. A bare str or an empty list raises ContractError.
metadataNone, a list of taco.Level, or a mapping from level name to {field: declaration} in the form COLLECTION.json stores. A level the structure does not imply raises ContractError.

structure is a tuple of declarations. levels starts with sample and children, then lists children/<folder> levels from shallowest to deepest in declaration order. metadata maps each level to its Field(type, nullable, description, files) values. operations holds the Python extension graph and is empty for a contract loaded from a dataset.

to_dict() serializes the contract and Contract.from_dict() parses it. Contracts compare equal when their serialized forms match.

contract.levels
contract.metadata["sample"]["quality:cloud_cover"]
contract.to_dict()["taco:metadata"]["sample"]["quality:cloud_cover"]
('sample', 'children')
Field(type='double', nullable=False, description='Cloud cover in percent', files=None)
{'type': 'double', 'nullable': False, 'description': 'Cloud cover in percent'}

The mapping form needs no Pydantic. A declaration takes one of three forms: a dict with type, nullable and an optional description; a canonical type string or pyarrow.DataType, for a field that is not nullable; or a (type, description) pair, for a nullable one:

taco.Contract(
    structure=["image.bin", "mask.bin"],
    metadata={"sample": {"quality:cloud_cover": {"type": "double", "nullable": False, "description": "Cloud cover in percent"}}},
)

Level

taco.Level(name, **groups)

Binds namespaces to a structure level named by name. Each keyword becomes a column prefix and must match [a-z][a-z0-9_]*; taco, internal and cozip are reserved.

Pass a Pydantic model class for a required group, Model | None for an optional group with nullable columns, or a taco.Extension instance to compute columns in run(). A level omitted from the list still stores its internal columns.

Each model field becomes a column. T | None makes it nullable, Field(description=...) gives its description, and Annotated[T, pyarrow_type] sets the exact type. Without Annotated the types map as follows:

str, bytes, boolstring, binary, bool
int, floatint64, double
datetime, date, Decimaltimestamp[us] without a timezone, date32, decimal128(38, 9)
list[T], tuple[T, ...]list<T>
tuple[T, T, T]fixed_size_list<T, 3>
dict[K, V]map<K, V>
Literal[...]The type shared by its values
a BaseModelstruct<...> of its fields

A plain datetime field then refuses a timezone-aware value: SampleError: invalid scene:date at 'children': timezone-aware datetime needs a timestamp with a timezone (expected timestamp[us], got datetime). Annotate it as the spatial and temporal profiles do. This contract binds a group to the folders and files under the sample, and another to the files in each folder:

from datetime import datetime, timezone
from typing import Annotated

import pyarrow as pa

TimestampUTC = Annotated[datetime, pa.timestamp("us", tz="UTC")]


class Scene(BaseModel):
    date: TimestampUTC = Field(description="Acquisition time")


class Band(BaseModel):
    name: str = Field(description="Band name")


pairs = taco.Contract(
    structure=["before/B02.bin", "after/B02.bin", "mask.bin"],
    metadata=[
        taco.Level("children", scene=Scene | None),
        taco.Level("children/before", band=Band),
        taco.Level("children/after", band=Band),
    ],
)
pairs.levels
('sample', 'children', 'children/before', 'children/after')

Collection

taco.Collection(*, contract, id, description, licenses, providers, tasks=None, title=None,
                curators=None, keywords=None, extent=None, sources=None, extensions=None, **groups)

The dataset description stored as COLLECTION.json. Every argument is a keyword.

contractA taco.Contract.
idA non-empty str without /, \, : or NUL. A new contract needs a new id.
descriptionA non-empty str.
licensesA non-empty sequence of str.
providersA non-empty sequence of names, or mappings with name and optional roles, url and links.
tasksA non-empty sequence of str. A value outside taco.contract.KNOWN_TASKS is a validation warning.
title, keywordsA str, and a sequence of str.
curatorsA sequence of names, or mappings with name or organization and optional email and role.
extentThe writer recomputes it on every build from the spatial or stac profile, so a value given here is not written.
sourcesReserved for a TACOCAT. open_writer refuses a collection that sets it.
extensionsJSON Schema URLs of published extensions that are not built in. The identifiers of built-in extensions are added from the namespaces the contract and the groups use.
**groupsCollection metadata, one keyword per namespace: a mapping or a Pydantic model instance. Field x of group g is stored as g:x, as Metadata describes.

collection.metadata holds the groups as JSON values. to_dict() returns a copy of the document; to_json() returns its text. Collection.from_dict() and Collection.from_json() parse those forms. from_json() requires UTF-8 JSON without NaN or Infinity and allows at most 256 nesting levels.

Invalid collection data raises CollectionError. An invalid contract raises ContractError; a missing required Python argument raises TypeError.

Collection.replace(**changes) -> taco.Collection

Returns a copy with some arguments or groups replaced. A group set to None is removed. Replacing the contract also drops the groups of built-in extensions the new contract does not use.

Encoding

taco.Encoding(name)

A Parquet encoding hint for one column: "dictionary", "plain", "byte_stream_split" or "delta". Another name raises ValueError. Put it in Annotated on a model field, or merge taco.Encoding(name).metadata into the field metadata of an extension output.

class Scene2(BaseModel):
    sensor: Annotated[str, taco.Encoding("dictionary")] = Field(description="Sensor name")

With this hint the scene:sensor column was written with RLE_DICTIONARY. Without a hint the writer writes up to 10,000 rows of each column in every encoding and keeps the smallest. Hints are not part of the contract. Passing use_dictionary, column_encoding or use_byte_stream_split in parquet_options turns the choice off and leaves the encodings to pyarrow.

open_writer

taco.open_writer(collection, output, *, append=False, overwrite=False, link=False,
                 row_group_size=65_536, batch_size=10_000, parquet_options=None,
                 partition_size=None, partition_by=None, progress=False, workers=1) -> Writer

Returns a writer for one build. An output ending in .zip gives a ZIP writer, any other path a FOLDER writer. It checks the arguments and does not touch the output, so an existing output raises FileExistsError from run().

collectionA taco.Collection without sources.
outputText or a path-like object. ~ is expanded.
appendFOLDER only. Adds the samples to an existing FOLDER dataset with the same id, contract and extension parameters. Excludes overwrite.
overwriteReplaces an existing output. A FOLDER writer still refuses a non-empty directory that is not a TACO folder.
linkFOLDER only. Hard-links file assets instead of copying them, so a source must be on the same file system.
row_group_sizeA positive int, the rows of each Parquet row group.
batch_sizeA positive int, the rows each level buffers before its extensions run. Finished batches are gathered into row groups of row_group_size rows.
parquet_optionsA mapping of pyarrow.parquet.ParquetWriter arguments, merged over compression="zstd", level 9, and write_statistics=True. row_group_size is not accepted here and raises ValueError from run().
partition_sizeZIP only. Payload bytes per partition, an int or text such as "4GB". Units are binary: "4GB" is 4 × 10243 bytes.
partition_byZIP only. A sample-level field other than id, one partition per value. It may be a field an extension produces.
progressShows tqdm bars while a ZIP build plans, writes metadata and packs, or while a FOLDER build writes. They stay silent when the output is not a terminal.
workersA positive int, the processes that build partitions; above 1 only with partition_size or partition_by. Workers start with spawn, so the collection, its models and extensions must be picklable and importable, not defined in a notebook, and a script needs an if __name__ == "__main__": guard.

Writer lifecycle

Writer.add(sample) -> int
Writer.extend(samples) -> int
Writer.run() -> taco.writer.BuildResult
Writer.close() -> None

add checks a taco.Sample against the contract, copies inline bytes into a staging directory, measures every file and stages the sample on disk. It returns the position of the sample in this writer. extend calls add for each item of any iterable, a generator included, and returns the new count. Neither touches the output.

run is the commit point: it runs extensions, plans ZIP offsets, writes Parquet files and publishes the result (writer lifecycle). A failed build preserves the existing output; another call after success returns the same result. Leaving the with block calls close to remove staging files. A writer that never ran publishes nothing.

def make(sample_id, split):
    return taco.Sample(
        id=sample_id,
        assets=[taco.Asset(b"image", path="image.bin"), taco.Asset(b"mask", path="mask.bin")],
        metadata=taco.Metadata(split=Split(split=split), quality=Quality(cloud_cover=0.0)),
    )


writer = taco.open_writer(collection, "life.zip", overwrite=True)
writer.state                                            # 'open'
writer.add(make("a", "train"))                          # 0
writer.extend([make("b", "test"), make("c", "test")])   # 3
built = writer.run()
writer.state                                            # 'succeeded'
writer.run() is built                                   # True
writer.add(make("d", "train"))
writer.close()

failedrun raised. add and run raise WriterError; open a new writer.
closedclose ran before run. Nothing was written.

A writer also has state, sample_count, collection, contract and result, which is None until a build succeeds. run with no samples raises WriterError: cannot build a dataset without samples. The BuildResult is a frozen dataclass:

pathpathlib.Path of the archive, the folder, or the .tacocat directory of a partitioned build.
samplesint, the samples in the dataset, the earlier ones included after an append.
data_filesint, the files this build stored.
metadata_filesint, one Parquet file per level.
sizeint bytes: the archive, the sum of the partitions, or the files a FOLDER build copied.
partstuple of partition paths, empty unless the build was partitioned.

New samples continue the existing indices. An append stages samples, Parquet levels and COLLECTION.json under .taco-append/. It moves the samples into DATA/, switches METADATA/ to commit, in one step where the system can swap two directories, as Linux and macOS can, and with two renames elsewhere, then publishes COLLECTION.json. Readers ignore the staging folder.

If the writer stops, the next append rolls back work before the metadata switch or completes work after it. Until recovery, validate may report extra samples in DATA/. A concurrent append raises WriterError: another writer is appending to <dataset>. An append also raises WriterError if the collection id, contract or extension parameters change, or if sample IDs repeat. To publish the folder as one archive, export it:

taco.export("growing", "growing.zip", sql="SELECT * FROM sample", overwrite=True).samples

Partitions and TACOCAT

partition_size and partition_by split a ZIP build into archives beside a .tacocat directory with merged metadata. See TACOCAT. Archive names follow <stem>_<value>.zip, <stem>_partNNNN.zip, or <stem>_<value>_partNNNN.zip when both options are set.

Values lose accents and unsafe filename characters become _: São Paulo in ds.zip produces ds_Sao_Paulo.zip. Labels that collide, ignoring case, receive -2, -3, and so on. A build with one partition writes a plain archive. Otherwise, it publishes the archives and catalog together.

splits = ["train", "train", "validation", "test"]
with taco.open_writer(collection, "parts/tiny.zip", partition_by="split:split", overwrite=True) as writer:
    writer.extend(make(f"p{i}", split) for i, split in enumerate(splits))
    built = writer.run()

Extensions

An extension adds fields at write time. Extensions lists the built-in ones and what each stores. This section shows how to bind them in Python and how to write one.

Built-in extensions

Sample extensions live under taco.extensions.sample and bind to a Level. Collection extensions live under taco.extensions.collection and bind to Collection. Each uses its declared namespace.

Pass profiles and plain models as classes, such as stac=STAC or split=Split. Pass operations as instances, such as majortom=MajorTOM(...) or rumi=Rumi(...). Collection extensions also use instances: ml=ML(...), labels=Labels(...) and instrument=Instrument(...).

Collection.extensions records schema URLs for extensions in use; Spatial belongs to STAC. MajorTOM reads stac:centroid unless centroid= selects another field. GeoEnrich uses the 10 km majortom:code by default, or the centroid with backend="earthengine".

The writer orders extensions by their required inputs. Missing inputs fail when the contract is built: ContractError: extensions at 'sample' require missing fields ['stac:centroid']. Binding a built-in to the wrong namespace also fails: ContractError: MajorTOM must use metadata namespace 'majortom', got 'mt'.

Some extensions do work at run(). Rumi reads each local .rumi file and needs taco-eo[rumi]. GeoEnrich with the default majortom-index backend downloads the Major TOM index into the cache and revalidates it on every build, and with backend="earthengine" it needs taco-eo[geoenrich] and Earth Engine credentials.

Writing an extension

Subclass taco.Extension, a frozen dataclass, and bind an instance in a Level. The writer calls run once per batch, after the files are local.

requiresA property: tuple[str, ...] of qualified fields it reads, from any group or another extension.
fieldsA property: pyarrow.Schema of unqualified output fields. The writer adds the namespace. At least one field.
run(context)Returns a mapping from each output field to a sequence with one value per row.
input_modelOptional property: a Pydantic model for values the producer also supplies, or None.
configuration()Optional: JSON values describing the setup, kept in Contract.operations while writing and not stored.
collection_metadata()Optional: parameters that change what a column means, stored in COLLECTION.json under the namespace and checked on append.
__taco_scopes__Class variable, the scopes the extension allows. A set without "sample" keeps it out of levels; the default, an empty set, allows it anywhere.
__taco_namespace__Class variable, the namespace the extension owns, or None to accept any.
__taco_complete_level__Class variable, True to receive the whole level as one batch.
__taco_row_local__Class variable, True to skip the check that the output of a row depends only on that row.

taco.ExtensionContext has level, a str; columns, a mapping from qualified field to the values of the batch; and assets, a tuple with the local Path of each row's file, or None for a folder row and for sample rows unless the structure is one fixed file.

from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from typing import Any, ClassVar

from taco.extensions.sample.stac import STAC


@dataclass(frozen=True)
class Pixels(taco.Extension):
    """Number of pixels in the sample grid."""

    __taco_scopes__: ClassVar[frozenset[str]] = frozenset({"sample"})

    @property
    def requires(self) -> tuple[str, ...]:
        return ("stac:proj_shape",)

    @property
    def fields(self) -> pa.Schema:
        return pa.schema([pa.field("count", pa.int64(), nullable=True, metadata={b"description": b"Pixels in the grid"})])

    def run(self, context: taco.ExtensionContext) -> Mapping[str, Sequence[Any]]:
        shapes = context.columns["stac:proj_shape"]
        return {"count": [None if shape is None else shape[0] * shape[1] for shape in shapes]}


tiles = taco.Collection(
    contract=taco.Contract(
        structure=["image.bin"],
        metadata=[taco.Level("sample", stac=STAC, majortom=MajorTOM(dist_km=10), pixels=Pixels())],
    ),
    id="lima-tiles",
    description="Two 256 by 256 tiles over Lima",
    licenses=["CC-BY-4.0"],
    providers=["Example Lab"],
)


def tile(sample_id, west):

        datetime=datetime(2024, 1, 1, tzinfo=timezone.utc),
    )
    return taco.Sample(id=sample_id, assets=sample_id.encode(), metadata=taco.Metadata(stac=grid))

STAC computed the float32 centroid from the grid, MajorTOM read it, and Pixels ran on the shapes. The writer summarized the extent from the same rows. To check that an output does not depend on its batch, the writer runs the first row of each level again on its own. An extension that ranks rows within the batch fails:

SampleError: extension group 'rank' depends on the other rows of its batch; it runs once per batch, so a value that aggregates across samples belongs in a collection summary

A private namespace such as pixels needs no identifier. For a published extension, pass its JSON Schema URL in Collection(extensions=[...]).

Validate, export and consolidate

The overview sums up these three calls under Validate, export, consolidate. They need the writer extra.

validate

taco.validate(path, *, check_data=True) -> taco.validate.ValidationReport

Checks a local dataset against the spec and collects all issues. It uses pyarrow and zipfile, so a URL is treated as a local path and reported as missing. For a TACOCAT, every listed partition must exist, pass ZIP validation and agree with the catalog's rows, sample count, collection metadata and summaries.

COLLECTION.json follows the core's strict JSON rules. A ZIP or FOLDER extent must match the writer's summary of its rows within 1e-9 degrees. Child rows must follow their parents and the structure, a field restricted to some files must be null on other rows, and MajorTOM codes must match their centroids. Up to 10 schema violations are reported per extension. Set check_data=False to skip payload and ZIP CRC-32 checks, which take time on large archives. The report has:

pathpathlib.Path, the path as given with ~ expanded.
container"zip", "folder", "tacocat", or None when the dataset could not be opened.
issueslist of Issue(severity, code, message) in the order found. severity is "error" or "warning".
errors, warningsThe issues of each severity.
okTrue when there are no errors. Warnings do not count.
raise_for_errors()Raises ValidationFailed listing every error.

The codes are container, id, sources, tasks, metadata, schema, current_id, parent_id, relative_path, structure, offsets, cozip, zip, data, source_file, extensions and profile, named after the rules of Validation. An issue inside a TACOCAT partition starts with its name, as in partition 'b.zip': payloads do not match their CRC-32: 'DATA/0/mask.tif'. Errors

The classes live in taco.errors, and their base is also exported as taco.TacoError. Errors on the overview gives the cause of each. Every class derives from TacoError and from a built-in exception, so except ValueError also catches the first four.

ContractErrorValueError. Raised by Contract, Level and Contract.from_dict.
TypeSpecErrorA ContractError, raised by taco.contract.parse_type for a type string that is not canonical. Contract raises it again as a ContractError that names the field.
SampleErrorValueError. Raised by Sample, Asset, Folder and Metadata, by add, and by run when an extension output does not fit.
CollectionErrorValueError. Raised by Collection, replace, from_dict and from_json.
WriterErrorRuntimeError. Raised by the writer methods, as Writer lifecycle describes.
ContainerErrorRuntimeError. Raised by open_dataset, read, read_bytes, inspect and export, and by the first open when the core cannot be loaded.
ConsolidationErrorRuntimeError. Raised by consolidate.
ValidationFailedRuntimeError. Raised by ValidationReport.raise_for_errors().

Argument checks raise plain ValueError or TypeError, an existing output raises FileExistsError, and a model value raises Pydantic's ValidationError. Dataset.sql raises DuckDB exceptions, all subclasses of duckdb.Error: ParserException for a syntax error such as an unquoted field, CatalogException for an unknown relation and BinderException for an unknown column.
