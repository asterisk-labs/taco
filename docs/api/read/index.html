Reading a TACO dataset

The same logical reader opens TACO folders, ZIPs, partition lists, and TACOCATs from Python, R, or Julia.

01Open and read

One reader in three languages

Every binding exposes the same dataset model. Use read for complete samples and SQL for filters or raw metadata.

import taco

dataset = taco.open_dataset("https://data.source.coop/major-tom/core-dem/")
samples = dataset.read(files="dem.rumi")
first_100 = dataset.sql('SELECT * FROM data WHERE "taco:sample_index" < 100')
library(taco)

dataset <- open_dataset("https://data.source.coop/major-tom/core-dem/")
samples <- read(dataset, files = "dem.rumi")
first_100 <- sql(dataset, 'SELECT * FROM data WHERE "taco:sample_index" < 100')
using Taco

dataset = Taco.open_dataset("https://data.source.coop/major-tom/core-dem/")
samples = Taco.read(dataset; files=["dem.rumi"])
first_100 = Taco.sql(dataset, 'SELECT * FROM data WHERE "taco:sample_index" < 100')
02Reader API

Read all samples or query a subset

OperationMeaning
dataset.read()Every sample, ordered by taco:sample_index.
dataset.read(files=...)The complete sample table with only the selected structural file columns.
dataset.sql(query)A partial query over data, files, or a named metadata level.
inspect(source, query)The contract, structure, levels, collection, profile, or core-generated SQL without reading samples.
