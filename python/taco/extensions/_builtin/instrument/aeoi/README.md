# Awesome Earth Observation Instruments

`catalogue.json` is an unmodified copy of the
[Awesome Earth Observation Instruments](https://github.com/awesome-spectral-indices/awesome-earth-observation-instruments)
catalogue (AEOI), by David Montero Loaiza and the Awesome Spectral Indices
contributors, distributed under the MIT license in `LICENSE`.

- Version: 0.4.0
- Source: https://github.com/awesome-spectral-indices/awesome-earth-observation-instruments/raw/refs/heads/main/catalogue/catalogue.json
- Commit: b050ccf016b2 (2026-09-10)
- Paper: "Towards an open registry of Earth observation instruments" (https://github.com/davemlz/srf-aeoi)

The TACO instrument extension reads instrument and band metadata from it. Run
`python tools/update_aeoi.py` to replace it with the latest release.
